# Usage

1. Dataset Manager -> validate or download a dataset.
2. Training -> train a model (or skip if you already have models/best_model.keras).
3. Upload Data -> load a before/after image pair.
4. Prediction -> Run Analysis.
5. Results / Visualization -> inspect mask, overlay, heatmap, regions.
6. Metrics -> Evaluate on Test Set for Accuracy/Precision/Recall/F1/IoU/Dice.
7. Report Generator -> export PNG/CSV/JSON/PDF.
8. History -> review past analyses stored in SQLite.
